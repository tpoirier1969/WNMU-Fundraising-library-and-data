Advanced filters proposed for the real page
Time controls
Season, year, exact start/end date, all historical data, or selected fundraiser only.
Program controls
Topic, secondary topic, distributor, length, rights status, NOLA/title search, active/archived.
Evidence controls
Minimum broadcasts, minimum seasons, show weak evidence, hide weak evidence, or flag weak evidence without hiding it.
Money controls
Total dollars, average dollars, median dollars, pledges, dollars per minute, exclude non-specific pledges.
Scheduling controls
Daypart, weekday/weekend, live break only, non-live only, first airing in drive, repeat airing in drive.
Record inspection
Show contributing broadcasts, source fundraiser, import source, and export/copy rows so no evidence disappears into dashboard fog.
