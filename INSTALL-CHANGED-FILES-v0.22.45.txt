Install v0.22.45 changed files

1. Back up the current app folder.
2. Unzip WNMU-Pledge-Program-Library-v0.22.45-changed-files.zip over the current app folder.
3. Confirm these changed files overwrite the existing files:
   - index.html
   - pledge-performance-lab.html
   - version.json
   - assets/js/core.js
   - assets/js/dom.js
   - assets/js/ui-performance.js
   - README-v0.22.45-start-time-performance.txt
4. Hard-refresh the browser.
5. Confirm the visible app version says v0.22.45.

This patch does not include config.js and does not change the database.
