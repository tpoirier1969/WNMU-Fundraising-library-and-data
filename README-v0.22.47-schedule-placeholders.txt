WNMU Pledge Program Library v0.22.47 — Schedule placeholders

Changed-files patch for v0.22.46 or later.

What changed:
- Adds placeholder/dummy program blocks to the Pledge Scheduling calendar.
- Right-click a calendar time slot and choose Add placeholder… to create a temporary block.
- Placeholder blocks store a typed title and chosen length without creating a fake program-library record.
- Clicking an existing placeholder opens the scheduling modal with the placeholder title preloaded as the program search, so matching real programs are offered immediately when possible.
- A placeholder can be edited, copied/pasted, dragged/moved, deleted, exported in the Daily Rundown, or replaced by selecting a real program match.
- Placeholders are visually distinct and are excluded from scheduled-program detail cards because they are not real pledge-library records yet.

No database schema changes.
No config.js included.
